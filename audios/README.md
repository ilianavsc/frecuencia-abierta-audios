# Carpeta de Audios Oficiales

Cualquier archivo de audio colocado en esta carpeta (`.mp3`, `.wav`, `.webm`, `.ogg`) con el nombre de su línea correspondiente (por ejemplo: `L0.webm`, `L1.mp3`, `L2.wav`, etc.) será detectado y cargado automáticamente por la aplicación web para cualquier persona que visite la página pública.

También puedes registrar los audios en `manifest.json`:
```json
{
  "L0": "audios/L0-ANDREA.webm",
  "L1": "audios/L1-ILIANA.webm"
}
```
O simplemente usar el botón **"📦 Descargar paquete (.zip)"** en la aplicación web para generar todo listo para descomprimir aquí.
